# Catalogo DummyJSON — plano aprovado

**Objetivo:** integrar somente o catalogo externo e snapshots locais, sem alterar schemas.
**Arquitetura:** contratos independentes; provider fetch/Zod; Repository Drizzle;
CatalogService coordena casos de uso; Controller valida/adapta HTTP; auth existente.
**Tecnologias:** Node 22 fetch nativo, Zod existente, Drizzle, PostgreSQL, node:test.

## Contratos e mapeamento

- ProductProvider: list, search, getById, categories; produtos normalizados e paginas
  `{ products, total, skip, limit }`, categorias como slugs.
- SnapshotRepository: findByExternalId, createIfAbsent, list, findById.
- CatalogUseCases: os sete casos de uso HTTP; sem dependencia de Express ou Drizzle.
- id externo -> externalId string; source dummyjson; UUID/data gerados localmente;
  descricao/imagem ausentes -> null; thumbnail ou primeira imagem.
- Atributos explicitamente permitidos: categoria, marca opcional, SKU, tags, imagens,
  dimensoes, peso, estoque, disponibilidade, garantia, envio, devolucao, quantidade
  minima e metadados tecnicos. Nao copiar reviews, dados pessoais ou preco.
- GETs exigem autenticacao; importacao exige AUCTIONEER. Controller nao aceita dados
  de produto no corpo da importacao. Categorias filtram /external?category=slug.
- limit padrao 30, intervalo 1..100; skip inteiro nao negativo ate 2147483647.
- Snapshot existente e imutavel e retorna sem HTTP externo. Novos imports usam
  transacao/advisory lock por source/id e nova verificacao antes do INSERT.
- Base de producao fixa https://dummyjson.com; timeout configuravel (padrao 5000ms).
  Erros: 404 produto inexistente, 502 resposta/status externo invalido, 503 rede,
  504 timeout. Nunca refletir corpo de erro remoto.

## Casos de borda

Marca ausente; imagens ausentes; paginas vazias; queries repetidas/invalidas; ID remoto
divergente do solicitado; JSON invalido; timeout durante leitura do corpo; falha de rede;
importacoes simultaneas; mudanca do produto remoto apos importacao; indisponibilidade
remota com snapshots ja importados; stripping de campos pessoais desconhecidos.
